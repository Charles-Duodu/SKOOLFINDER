2. Production Architecture & Backend Recommendation

The Recommended Market Backbone: Node.js/Express + Neon PostgreSQL
Standardize on Node.js/Express + Neon PostgreSQL as your single source of truth. Remove the redundant Supabase database and Clerk keys from .env to eliminate confusion and simplify maintenance.
❌ What to Retire / Clean Up
  • Supabase (Database): Having both DATABASE_URL (Neon) and SUPABASE_URL causes architectural duplicate storage. Neon is already tested, connected, and active (v16.15).
  • Clerk Auth: Ghanaian parents and educators interact with phone numbers and SMS OTPs. Your platform already has a native Ghana Phone OTP + JWT engine, making Clerk's external hosted popups unnecessary.
✅ What to Retain (The 4 Pillars)
  • Neon PostgreSQL: High-performance serverless cloud relational database storing all 33 business collections.
  • Paystack Ghana: Handles automated Mobile Money (MTN MoMo, Telecel, AT) and card fee payments.
  • Hubtel SMS: Direct telecom SMS delivery for parent OTPs and fee payment receipts.
  • Resend Email: Delivery of formal PDF receipts, LPO purchase orders, and employment contracts.
Will Removing Supabase or Clerk Affect the 5 Portals?
No. Absolutely 100% of the 5 portals will continue to work perfectly.
All 5 portals (Parents, Teachers, Suppliers, Schools, and Admin) are built into your own Single-Page Application (parentDashboardView.js, teachersView.js, suppliersView.js, dashboardView.js, and adminView.js). Routing is managed by public/js/app.js and data is served by server.js via Neon PostgreSQL. You will not lose a single page, button, or feature.

4. Administrator Command Line Cheatsheet

Run these commands from the project root directory in PowerShell or terminal:

COMMAND WHAT IT DOES
npm run gateways:verify Health Diagnostic Suite: Tests live connectivity and latency to Neon PostgreSQL, checks Paystack and Hubtel credentials, and prints a deployment readiness checklist.
npm run backup Manual Snapshot: Immediately creates a timestamped JSON backup snapshot of all 33 collections inside the backups/ directory.
npm run db:migrate Database Sync & Migration: Pushes and syncs all institutions, tenders, quotes, and users from the local document store into the Neon PostgreSQL cloud database.
npm start or npm run dev Boots the Application Server: Starts the Express.js gateway on port 3000 with active PostgreSQL connection pooling and background health monitors.

5. Pre-Market Launch Checklist

  1. Switch Paystack to Live Mode: In .env, replace pk_test_... and sk_test_... with your live keys from the Paystack Ghana dashboard. Add your PAYSTACK_WEBHOOK_SECRET.
  2. Register Hubtel Sender ID: Ensure your Sender ID (SkoolFinder) is registered with the National Communications Authority (NCA) via Hubtel Unity, then insert your live Client ID and Secret in .env.
